# Goenner2026_Decoding_Sequence_Dynamics

Simulates hippocampal place cell activity during spatial sequences and analyzes Bayesian decoding accuracy.

The code in this repository is used to investigate whether place-cell sequences exhibit step-like movement (discrete attractor dynamics) or continuous movement (continuous attractor dynamics). We show that the previous decoding approach is prone to artifacts and propose a modified method to better distinguish continuous from discrete dynamics in place-cell sequences.

## Dependencies
  
The neurosimulator ANNarchy 4.8 was used for data generation. Please note that ANNarchy is only supported on the following operating systems: 

- GNU/Linux
- MacOS X
- Windows (inside WSL2)

For detailed information, please visit the [ANNarchy repository](https://github.com/ANNarchy/ANNarchy).

Additional dependencies are declared in the requirements.txt file and can be installed using pip:

```bash
pip install -r requirements.txt
```

All analyses and simulations were performed using Python 3.12.


## Data Generation

`sim_params_seq.py` - Parameter configuration file defining simulation settings for different parameter sets. A priori simulations used param_id = 4, while data-anchored simulations used param_id = 16.

`create_data_apriori.sh` - Generates Poisson spiking data using a priori chosen parameters, for both smooth and speed-modulated movement conditions. Please set param_id to 4 in `sim_params_seq.py`.

`create_data_percell_rates.sh` - Generates data-anchored Poisson spiking data, with per-cell rates fitted to Pfeiffer and Foster (2015), for both smooth and speed-modulated movement conditions. Please set param_id to 16.

`create_bias_analysis.sh` - Runs the data-anchored simulation repeatedly (default: 30 runs) across a range of `n_cells`, to characterize step-size estimation bias as a function of population size. Please set the seed to None for randomization.

`ann_contextosc_nodelay.py` - Goal-directed navigation network with oscillatory dynamics (Fig. 12).

## Data Analysis

`ann_bayes_decode.py` - Bayesian decoding of spike trains generated by the continous attractor network from Gönner et al. (2017) (Fig. 2).

`comp1_addpositions_hilbert.py` - Phase-dependent analysis using Hilbert transform (Fig. 4).

`comp3_ricedist_speedmod_const.py` - Fits Rice and Rayleigh distributions to decoded step sizes (Fig. 5).

`analysis_spearman_phase.py` - Computes Spearman correlation between decoded step size and theta phase (multiple Figs).

`exp_analysis/trajectory_analysis_python.ipynb` - Analysis of experimental data from Pfeiffer and Foster (2015).

`analysis_step_size_bias.py` and `analysis_combined_speeds.py`- Analysis of 2D step-size estimation bias as a function of population size (Fig. 11).

## Utilities

`plotting_func.py` - Plotting functions for trajectories, firing maps, and decoding results.

`circ_stats.py` - Circular statistics functions (circular-linear correlation).

`new_colormaps.py` - Colormap definitions

`azizi_newInitLearn.py` - Spiking place cell network initialization (only used for imports).

`exp_analysis/utils.py` - Utility functions for data processing and analysis.
